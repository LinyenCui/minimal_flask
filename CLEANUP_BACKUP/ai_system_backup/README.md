# LineBot派班系统

这是一个使用Flask和LINE Messaging API开发的派班系统，用于管理司机和班次。系统使用PostgreSQL数据库存储数据。

## 功能特点

- 管理客户、司机和班次信息
- 支持固定班次和临时班次
- 自动导入固定班次
- 指派司机到班次
- 更改班次状态
- 查询司机班次和日期班次
- 生成周报表
- 使用 Flex Message 实现更友好的用户界面
- 班次状态管理（待派、準備、取消、衝突、請假、完成）

## 本地开发环境设置

### 前提条件

- Python 3.8+
- PostgreSQL 12+
- ngrok (用于本地测试LINE Bot)

### 安装步骤

1. 克隆仓库：

```bash
git clone <repository-url>
cd minimal_flask
```

2. 创建并激活虚拟环境：

```bash
python -m venv venv
source venv/bin/activate  # 在Windows上使用: venv\Scripts\activate
```

3. 安装依赖：

```bash
pip install -r requirements.txt
```

4. 配置环境变量：

创建或编辑`.env`文件，添加以下内容：

```
LINE_CHANNEL_TOKEN=你的LINE_CHANNEL_TOKEN
LINE_CHANNEL_SECRET=你的LINE_CHANNEL_SECRET
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/dispatch_system
```

5. 初始化数据库：

```bash
python init_db.py
```

6. 启动ngrok：

```bash
ngrok http 3000
```

7. 更新LINE Bot的Webhook URL为ngrok提供的URL，例如：
   `https://xxxx-xxx-xxx-xx-xx.ngrok-free.app/callback`

8. 启动应用：

```bash
python app.py
```

## 使用指南

系统支持以下命令：

1. `新增固定 周期 时间 起点 经由 到达 表价 加成 实收 分类 司机` - 添加固定班次
2. `匯入固定 YYYY-MM-DD` - 导入指定日期的固定班次
3. `新增 日期 时间 起点 经由 到达 表价 加成 实收 分类` - 添加临时班次
4. `指派 班次ID 司机ID` - 指派司机到班次
5. `更改狀態 班次ID 新状态` - 更改班次状态（舊命令）
6. `修改狀態 班次ID 新状态` - 修改班次状态（新命令）
7. `確認取消 班次ID` - 确认取消班次
8. `確認請假 班次ID` - 确认将班次设为请假状态
9. `查車 司机ID 日期` - 查询司机在指定日期的班次
10. `查詢 日期` - 查询指定日期的所有班次
11. `生成周報表 [分類]` - 生成上周的周报表，可选指定分类
12. `班次詳情 班次ID` - 查看班次详细信息
13. `幫助` - 显示帮助信息
14. `顯示文字版幫助` - 显示文字版帮助信息

### 班次状态说明

系统支持以下班次状态：

- **待派**：班次尚未指派司机
- **準備**：班次已指派司机并准备执行
- **取消**：班次已被取消
- **衝突**：班次出现冲突，无法由原定司机完成
- **請假**：客户请假，影响后续周期的固定班次
- **完成**：班次已正常完成

## 系统设计说明

### 日期与时间处理

1. **周的定义**：
   - 本系统中，星期日被视为一周的第一天
   - 星期六被视为一周的最后一天
   - 所有与周相关的计算都基于这一定义

2. **日期表示**：
   - 数据库中日期以 YYYY-MM-DD 格式存储
   - 显示给用户时使用 MM/DD 或 YYYY/MM/DD 格式

3. **星期表示**：
   - 数据库中星期以数字表示：0=星期日, 1=星期一, ..., 6=星期六
   - 显示给用户时使用中文：日, 一, 二, 三, 四, 五, 六

### 固定班次汇入

执行「汇入固定班次」命令时，系统会：
1. 计算当前所在周的星期日至星期六
2. 将固定班次表中的记录汇入到对应的日期
3. 避免重复汇入相同的班次

### 周报表生成

执行「生成周报表」命令时，系统会：
1. 计算上一周的日期范围（上周日至上周六）
2. 查询该日期范围内已完成班次
3. 生成Excel报表并可选上传至Google Drive

### 班次状态管理

系统支持多种班次状态，并实现了状态转换逻辑：

1. **状态转换规则**：
   - 从「待派」到「準備」需要先指派司机
   - 「取消」和「請假」状态需要用户确认
   - 「請假」状态仅适用于固定班次

2. **状态确认流程**：
   - 当用户尝试将班次设为「取消」状态时，系统会要求确认
   - 当用户尝试将固定班次设为「請假」状态时，系统会提醒这将影响后续周期的班次并要求确认

3. **状态显示**：
   - 在班次详情中显示当前状态
   - 提供修改状态的指引和可用状态列表
