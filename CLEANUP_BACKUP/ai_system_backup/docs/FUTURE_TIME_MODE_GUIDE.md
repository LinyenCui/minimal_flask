# 未來時間態 (Future Time Mode) 使用指南

## 概述
未來時間態專門處理未來的班次規劃和預約，包括固定班次的匯入管理。本系統採用陽曆週次（星期日至星期六）的循環週期，確保班次規劃的準確性和一致性。

## 核心功能

### 1. 固定班次匯入系統
支援自然語言週次參數，提供智能化的班次規劃工具。

#### 基本命令格式
```
匯入固定班次 [週次] [覆蓋]
```

#### 週次參數支援
- `本週` / `這週` → 當前週次
- `下週` / `下一週` → 下一週次
- `上週` / `上一週` → ❌ 拒絕（過去時間態保護）

#### 覆蓋選項（可選）
- `覆蓋` → 覆蓋已存在的該週次固定班次

### 2. 使用範例

#### 基本匯入
```
匯入固定班次              # 顯示可用選項
匯入固定班次 本週         # 匯入本週固定班次
匯入固定班次 下週         # 匯入下週固定班次
```

#### 覆蓋模式匯入
```
匯入固定班次 本週 覆蓋    # 覆蓋本週已存在的固定班次
匯入固定班次 下週 覆蓋    # 覆蓋下週已存在的固定班次
```

### 3. 重複檢查機制

當檢測到已匯入過該週次的固定班次時：
```
⚠️ 本週 (7/13-7/19) 的固定班次已經匯入過了（共 133 筆）。

如需覆蓋，請使用：
🔄 匯入固定班次 本週 覆蓋

⚠️ 注意：如選覆蓋資料，原先對班次的修改會失效
```

### 4. 操作模式

#### 本週模式（追加模式）
- 在現有班次基礎上追加新班次
- 自動檢查重複，避免重複匯入
- 適合補充遺漏的班次

#### 下週模式（規劃模式）
- 如果沒有覆蓋選項，會自動將未完成班次移至已完成表
- 清空現有班次後匯入新週次
- 適合全新週次的規劃

### 5. 安全機制

#### 過去時間態保護
```
匯入固定班次 上週         # ❌ 拒絕操作
> 不允許匯入過去時間態：上週 (2025-01-19 至 2025-01-25)
```

#### 覆蓋保護
- 只有明確指定「覆蓋」選項才會替換現有班次
- 覆蓋會導致原先的班次修改失效
- 提供詳細的警告信息

### 6. 週次計算邏輯

#### 陽曆週次系統
- 採用國際標準：星期日為一週開始
- 週次循環：星期日(0) → 星期六(6)
- 確保跨月份週次計算正確

#### 週次邊界處理
- 自動處理跨月份的週次
- 智能識別週次邊界
- 防止週次重疊或遺漏

## 最佳實踐

### 1. 週次規劃建議
- 建議在週六或週日進行下週規劃
- 使用「清理已完成」選項定期清理歷史資料
- 避免在週中大量修改固定班次

### 2. 清理策略
- 每週匯入時使用「清理已完成」保持資料庫整潔
- 需要重新規劃時使用「清理全部」
- 定期備份重要資料

### 3. 錯誤預防
- 確認週次參數正確
- 謹慎使用清理選項
- 留意系統提示訊息
- 定期檢查匯入結果
