# 修復 `handle_update_trip_status` 未定義錯誤的步驟

## 問題描述

在實現班次狀態修改功能時，出現了 `name 'handle_update_trip_status' is not defined` 錯誤。這是因為在 Python 中，函數必須在被調用之前定義，而我們的 `handle_update_trip_status` 函數定義在文件的後面，但在前面的 `handle_text_message` 函數中就已經調用了它。

## 修復步驟

1. 將 `handle_update_trip_status` 函數及其相關的 `handle_confirm_cancel_trip` 和 `handle_confirm_leave_trip` 函數移到文件前面，確保它們在被調用之前已經定義。

2. 具體操作：
   - 找到這三個函數的定義（在文件末尾附近）
   - 將它們剪切並粘貼到文件前面，例如在 `app = Flask(__name__)` 之前
   - 刪除原來位置的函數定義，以避免重複定義

3. 如果使用編輯器難以完成這個操作，可以使用以下命令行操作：
   ```bash
   # 備份原文件
   cp app.py app.py.bak
   
   # 提取前面部分（直到需要插入函數的位置）
   head -n <插入位置行號> app.py > app_part1.py
   
   # 提取要移動的函數
   sed -n '<函數開始行號>,<函數結束行號>p' app.py > app_functions.py
   
   # 提取中間部分（從插入位置到函數開始位置）
   sed -n '<插入位置行號+1>,<函數開始行號-1>p' app.py > app_part2.py
   
   # 提取結尾部分（從函數結束位置到文件末尾）
   tail -n +<函數結束行號+1> app.py > app_part3.py
   
   # 組合新文件
   cat app_part1.py app_functions.py app_part2.py app_part3.py > app_new.py
   
   # 替換原文件
   mv app_new.py app.py
   
   # 清理臨時文件
   rm app_part1.py app_functions.py app_part2.py app_part3.py
   ```

4. 或者使用更簡單的方法：
   ```bash
   # 提取前面部分和要移動的函數
   head -n <插入位置行號> app.py > app_new.py
   sed -n '<函數開始行號>,<函數結束行號>p' app.py >> app_new.py
   
   # 提取中間部分（從插入位置到函數開始位置）
   sed -n '<插入位置行號+1>,<函數開始行號-1>p' app.py >> app_new.py
   
   # 提取結尾部分（從函數結束位置到文件末尾，但不包括要移動的函數）
   sed -n '<函數結束行號+1>,<函數開始行號-1>p' app.py >> app_new.py
   tail -n +<函數結束行號+1> app.py >> app_new.py
   
   # 替換原文件
   mv app_new.py app.py
   ```

5. 重啟應用程序，確認錯誤已修復。

## 預防措施

為了避免類似問題再次發生，建議：

1. 在開發過程中遵循「先定義後使用」的原則
2. 將常用的函數放在文件的前面
3. 考慮將相關功能模塊化，放在單獨的文件中，然後通過導入使用
4. 在添加新功能時，先檢查函數的依賴關係，確保所有被調用的函數都已定義
