## 🕐 三時間態架構 (Three Time Perspectives)

### 核心概念
派班系統的所有操作都基於三個時間態進行分類和路由：

### 1. 過去時間態 (Past)
**定義**: 查詢和分析已完成的歷史數據

**關鍵字**: 
- 時間表達：`昨天`、`前天`、`上週`、`上個月`、`去年`
- 狀態表達：`已完成`、`完成的`、`結束的`、`歷史`

**數據源**: 
- `completed_trips` 表（已完成班次記錄）
- 歷史報表數據
- 過往統計信息

**典型查詢**:
```
用戶輸入: "昨天司機533診所班次"
AI理解: 查詢昨天司機533的已完成診所班次記錄
路由到: query_completed_trips(date='昨天', driver_id=533, category='診所')
```

**業務邏輯**:
- 所有過去時間查詢都應該路由到已完成班次系統
- 不能修改歷史數據，只能查詢和分析
- 用於生成報表、分析效率、統計收入

### 2. 現在時間態 (Present)  
**定義**: 管理當前進行中的班次和即時操作

**關鍵字**:
- 時間表達：`今天`、`現在`、`當前`、`目前`
- 狀態表達：`準備`、`待派`、`進行中`

**數據源**:
- `trips` 表（當前班次記錄）
- 實時狀態信息

**典型查詢**:
```
用戶輸入: "今天診所班次"
AI理解: 查詢今天的診所班次安排
路由到: query_clinic_trips(date='今天')
```

**業務邏輯**:
- 可以修改狀態：待派 → 準備 → 完成
- 可以指派司機、修改類別
- 實時操作，影響當前業務

### 3. 未來時間態 (Future)
**定義**: 規劃和安排未來的班次

**關鍵字**:
- 時間表達：`明天`、`後天`、`下週`、`下個月`
- 操作表達：`安排`、`規劃`、`預約`、`匯入`

**數據源**:
- `fixed_schedules` 表（固定班次模板）
- 新班次創建

**典型查詢**:
```
用戶輸入: "匯入下週固定班次"
AI理解: 將固定班次模板匯入到下週的班次表
路由到: import_fixed_schedules(week='下週')
```

**業務邏輯**:
- 從模板創建新班次
- 可以批量操作
- 預先規劃和準備

## 🧠 AI系統期望與理想狀態

### 當前痛點
現有的"AI"系統實際上是美化版的if/else規則引擎，無法真正理解用戶的自然語言意圖。

### 理想狀態描述

#### 1. 自然語言理解
**期望**: AI能夠理解複雜的自然語言查詢，而不僅僅是關鍵字匹配

**示例**:
```
用戶輸入: "上個月效率最高的司機是誰？"
當前系統: 無法理解（沒有預設關鍵字）
理想AI: 自動分析completed_trips表，計算每個司機的效率指標，返回排名結果
```

#### 2. 動態資料庫操作
**期望**: AI知道PostgreSQL資料庫結構，能夠動態生成SQL查詢

**系統知識要求**:
- 完整的資料庫schema
- 表之間的關係
- 業務規則和約束
- 索引和性能考量

**示例**:
```
用戶輸入: "這週收入比上週少了多少？"
AI動作:
1. 理解需要對比兩個時間段的收入
2. 自動生成SQL查詢completed_trips表
3. 計算兩週的總車資差異
4. 分析可能的原因
5. 提供改進建議
```

#### 3. 功能組合與編排
**期望**: AI能夠組合使用現有的功能來完成複雜任務

**可用功能清單**:
- 查詢班次 (query_trips, query_completed_trips)
- 司機管理 (assign_driver, driver_performance)
- 報表生成 (generate_reports)
- 數據分析 (analyze_efficiency, compare_periods)
- 系統維護 (cleanup_trips, fix_sequences)

**示例**:
```
用戶輸入: "幫我安排明天雨天的班次調整"
AI編排:
1. 查詢明天的天氣預報
2. 獲取明天的班次安排
3. 識別容易受天氣影響的路線
4. 重新分配有經驗的司機
5. 增加備用司機待命
6. 發送調整通知
```

#### 4. 智能回應與引導
**期望**: 當無法完成任務時，AI能夠：
- 禮貌地說明無法完成的原因
- 提供替代方案
- 引導用戶使用正確的操作方式

**示例**:
```
用戶輸入: "幫我預測下個月的客戶需求"
AI回應: "抱歉，我目前沒有預測功能。但我可以幫您：
1. 分析過去6個月的客戶需求趨勢
2. 查看去年同期的數據對比
3. 生成需求分析報表
您希望我執行哪一個？"
```
