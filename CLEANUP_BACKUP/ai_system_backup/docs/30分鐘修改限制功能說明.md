# 班次執行前30分鐘修改限制功能

## 🎯 功能概述

這個功能實現了**班次執行前30分鐘內不允許修改狀態**的限制，防止臨時變更影響排班穩定性。

## ✨ 功能特點

### 1. 智能時間檢查
- 班次執行前30分鐘內，無法修改狀態
- 班次執行後，也無法修改狀態（已有功能）
- 自動計算剩餘可修改時間
- 支援台灣時區，精確時間計算

### 2. 用戶界面優化
- **Flex Message**: 在限制期間顯示紅色提示訊息
- **Quick Reply**: 在限制期間隱藏所有狀態修改按鈕
- **清晰提示**: 區分「執行前30分鐘限制」和「班次已過期」

### 3. 功能範圍
- **限制範圍**: 僅限制狀態修改功能
- **不受限制**: 指派司機功能仍可正常使用
- **向下兼容**: 對於沒有時間的班次，預設允許修改

## 🔧 技術實現


### 2. 核心方法
```python
class Trip(db.Model):
    def can_modify_status(self):
        """檢查班次狀態是否可以修改（執行前30分鐘內不可修改）"""
        
    def minutes_until_restriction(self):
        """返回距離進入限制期還有多少分鐘"""
        
    def get_restriction_message(self):
        """獲取限制提示訊息"""
```

### 3. 修改的文件
- `modules/models/trip.py` - 添加基於執行時間的檢查方法
- `modules/services/postback_service.py` - 添加修改限制檢查
- `modules/flex_designs/trip_details_flex.py` - 根據限制調整UI顯示

## 🛠️ 自定義設置

如需修改限制時間，可在 `modules/models/trip.py` 中調整：

```python
def can_modify_status(self):
    # 計算30分鐘前的時間點
    restriction_start_time = trip_datetime - timedelta(minutes=30)  # ← 這裡修改
    
    # 如果當前時間已經超過限制開始時間，則不能修改
    return current_time < restriction_start_time
```
