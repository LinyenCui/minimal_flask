## 差異摘要

主要差異：

- 健保碼尾碼不同：`100` vs `1G0`
- 有效起日不同：
  - `AC58534100`：2015-08-01
  - `AC585341G0`：2015-12-01
- 支付價不同：
  - `AC58534100`：1.50
  - `AC585341G0`：2.00

## 可能原因
