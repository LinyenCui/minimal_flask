# 📚 增強版幫助系統使用指南

## 🎯 系統概述

全新的分層級幫助系統已經完成！現在用戶可以通過 LINE Bot 直接獲得所有功能的完整說明，不再需要翻看各種 MD 文檔或 Cursor 歷史記錄。

## 🏗️ 系統架構

### 📋 分層設計

```
幫助 → 📚 系統功能總覽
├── 🎯 常用功能
│   ├── 🔍 查詢班次
│   ├── 🏥 診所班次  
│   └── 📝 預約叫車
├── 🚀 進階功能
│   ├── 🤖 AI功能說明
│   ├── 📋 固定班次功能
│   └── 🔧 請假與狀態
└── ⚙️ 管理功能
    ├── 📊 報表與匯出
    └── 🛠️ 維護工具
```

### 🔄 交互流程

1. **用戶輸入「幫助」** → 顯示主功能總覽
2. **點擊分類按鈕** → 進入詳細說明頁面
3. **點擊「返回幫助」** → 回到主頁面
4. **輸入「完整指令」** → 查看所有指令列表

## 📖 功能說明

### 🎯 常用功能
- **查詢班次**: 東洋/臨時班次查詢
- **診所班次**: 診所班次專用查詢
- **預約叫車**: AI 自然語言預約

### 🚀 進階功能

#### 🤖 AI功能說明
- **AI車資查詢**: 智能檢測車資相關查詢
  - `查詢今天車資`
  - `查詢台中車資`
  - `修改班次123車資500`
- **預約叫車AI**: 自然語言描述預約需求
- **使用技巧**: AI檢測機制和組合查詢

#### 📋 固定班次功能
- **查詢功能**: `/固定班表 [客戶簡稱]`
- **匯入功能**: `匯入固定班次 [月/日]`
- **長期請假**: 住院、出國等長期請假設定
  - `固定班次請假 [ID] [加成] [原因]`
  - `固定班次恢復 [ID]`

#### 🔧 請假與狀態
- **乘客請假**: `乘客請假 [班次ID] [加成] [原因]`
- **狀態修改**: 通過班次詳情修改狀態
- **30分鐘限制**: 執行前30分鐘不可修改狀態
- **統一邏輯**: 請假不改變業務流程狀態

### ⚙️ 管理功能

#### 📊 報表與匯出
- **週報表功能**: `生成周報表 [類別]`
- **Google Drive**: 自動上傳到對應資料夾
- **查詢功能**: `查已完成 [日期] [類別]`
- **報表特色**: Excel格式，動態標題，合併說明欄位

#### 🛠️ 維護工具
- **系統維護**: 更新已完成班次、待派班次查詢
- **資料修復**: `/fix-sequence` 修復序列問題
- **車資管理**: 記錄車資、修改類別
- **注意事項**: 謹慎使用，建議先備份

## 🎨 設計特色

### 🎨 視覺設計
- **分類標題**: 使用不同顏色區分功能類別
- **按鈕配色**: 主功能用 primary，進階功能用 secondary
- **圖標系統**: 每個功能都有對應的 emoji 圖標
- **返回導航**: 所有子頁面都有返回主幫助的按鈕

### 🔄 交互設計
- **階層導航**: 清晰的主頁→詳情→返回流程
- **按鈕觸發**: 使用 postback 而非 message 避免指令衝突
- **文字後備**: 同時支援「完整指令」文字版查看
- **群組友好**: 按鈕操作在群組中無需前綴
