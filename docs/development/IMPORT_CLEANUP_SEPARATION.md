# 匯入固定班次與清理功能分離改進

## 改進背景

原本的設計將匯入固定班次和清理trips資料兩個功能混在一起，導致使用上的混亂和邏輯不清。根據用戶反饋，我們將這兩個功能完全分離，各自獨立運作。

## 改進內容

### 1. 匯入固定班次功能（純粹化）

#### 改進前的問題
- 混合了清理功能，造成邏輯混亂
- 清理選項不符合實際需求
- 覆蓋機制不夠明確

#### 改進後的特點
- **純粹匯入**：只處理固定班次的匯入
- **明確覆蓋**：使用「覆蓋」選項替換已存在的班次
- **清晰警告**：明確告知覆蓋會讓原先修改失效

#### 命令格式
```
匯入固定班次 [週次] [覆蓋]
```

#### 使用範例
```
匯入固定班次 本週          # 匯入本週班次
匯入固定班次 下週          # 匯入下週班次
匯入固定班次 本週 覆蓋     # 覆蓋本週已存在的班次
```

#### 重複檢查機制
當檢測到重複時，提供明確的覆蓋選項：
```
⚠️ 本週 (7/13-7/19) 的固定班次已經匯入過了（共 133 筆）。

如需覆蓋，請使用：
🔄 匯入固定班次 本週 覆蓋

⚠️ 注意：如選覆蓋資料，原先對班次的修改會失效
```

### 2. 清理trips功能（獨立化）

#### 新功能特點
- **完全獨立**：與匯入功能無關
- **時間保護**：只清理過去的資料
- **狀態選擇**：可選擇清理已完成或所有過去班次

#### 命令格式
```
清理trips [選項]
```

#### 可用選項
- `已完成` - 清理所有已完成狀態的班次
- `過去` - 清理所有過去日期的班次  
- `全部` - 清理所有過去日期的班次（包括已完成和未完成）

#### 使用範例
```
清理trips                # 顯示清理選項
清理trips 已完成         # 清理已完成狀態的班次
清理trips 過去           # 清理過去日期的班次
清理trips 全部           # 清理所有過去日期的班次
```

#### 安全機制
- **時間保護**：不影響今天和未來的班次
- **狀態保護**：只清理指定狀態的班次
- **事務保護**：出錯時自動回滾

## 用戶體驗改善

### 1. 功能分離清晰
- **匯入**：專門處理固定班次匯入
- **清理**：專門清理trips表資料
- **各自獨立**：互不干擾

### 2. 覆蓋機制明確
- **明確選項**：使用「覆蓋」而非「清理」
- **警告提示**：明確告知會失效原先修改
- **安全確認**：必須明確指定才會覆蓋

### 3. 清理功能實用
- **時間保護**：不影響當前和未來班次
- **選擇性清理**：可選擇清理已完成或全部過去班次
- **效能提升**：定期清理保持系統效能
