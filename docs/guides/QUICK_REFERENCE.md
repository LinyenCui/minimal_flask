## 🔥 常用查詢命令

### 生產線監控（現在態）
```bash

今天東洋班次
今天診所班次

# 司機專屬查詢  
明天司機5386所有班次

狀態為衝突的班次
```

```bash
# 績效統計
```

## 🤖 AI智能查詢技巧

### 自然語言範例
| 用戶輸入 | AI理解 | 生成命令 |
|----------|--------|----------|
| "明天司機5386所有班次" | 查詢生產線明天該司機班次 | `查詢班次 明天 司機5386` |
| "今天金額大於200的診所班次" | 查詢成品倉庫高價值班次 | `查已完成 今天 診所 金額>200` |
| "找狀態為待派的班次" | 查詢生產線待派狀態 | `查詢班次 狀態=待派` |

### 查詢優化建議
- ✅ **明確時間**：今天、明天、昨天
- ✅ **指定司機**：司機編號 + 查詢條件
- ✅ **限定類別**：診所、東洋、臨時
- ✅ **使用狀態**：待派、準備、已完成

## ⚡ 狀態速查表

### 班次狀態
| 狀態 | 含義 | 可操作 |
|------|------|--------|
| **待派** | 等待指派司機 | ✅ 指派司機、取消 |
| **準備** | 已指派待執行 | ✅ 請假、取消、衝突 |
| **已完成** | 自動完成 | ✅ 查看、統計 |
| **取消** | 手動取消 | ❌ 不執行 |
| **衝突** | 異常標記 | ❌ 不執行 |

### 請假狀態（障眼法）
| 顯示 | 實際狀態 | 說明 |
|------|----------|------|
| **請假（原因）** | 準備 | 會正常執行流程 |
| **取消** | 取消 | 不會執行 |
| **衝突** | 衝突 | 不會執行 |

## 🎯 日常工作流程

### 早晨檢查 (08:00)
1. `今天東洋班次` - 查看東洋班次安排
2. `今天診所班次` - 查看診所班次安排  
3. `找狀態為待派的班次` - 處理未指派班次

### 中午確認 (12:00)
1. `明天司機[ID]所有班次` - 確認各司機明日安排
2. 處理請假申請
3. 解決衝突班次

### 晚間結算 (18:00)
1. `查已完成 今天` - 查看當日完成狀況
2. `昨天司機[ID]的車資` - 核對收入
3. 更新明日安排
