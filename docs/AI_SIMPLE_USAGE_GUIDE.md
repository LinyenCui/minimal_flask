# 🤖 AI車資查詢系統 - 簡化版使用指南

## 🎯 功能特色

### ✨ 主要改進
- **一次顯示所有結果** - 不再使用翻頁功能，所有搜尋結果一次呈現
- **智能檢測** - 自動識別車資相關查詢請求
- **簡潔回覆** - 清晰的文字格式，易於閱讀
- **即時修改** - 支援車資金額的快速修改

## 🔍 AI查詢功能

### 支援的查詢方式

#### 1. 基本車資查詢
```
查詢今天車資
查詢明天車資
查詢台中車資
查詢彰化車資
查詢診所車資
```

#### 2. 特定日期查詢
```
查詢6/1車資
查詢6/2台中車資
查詢6/3彰化費用
```

#### 3. 路線查詢
```
查詢台中到彰化車資
查詢診所到台中費用
查詢彰化到診所價格
```

#### 4. 組合查詢
```
查詢今天台中車資
查詢明天診所到彰化費用
查詢6/1台中到彰化車資
```

### 🔧 AI修改功能

#### 支援的修改方式
```
修改班次123車資500
設定班次456車資300
改班次789車資800
```

## 🎯 使用範例

### 範例1：查詢今天的車資
**輸入：** `查詢今天車資`

**AI回覆：** 顯示今天所有班次的車資信息

### 範例2：查詢特定地點
**輸入：** `查詢台中車資`

**AI回覆：** 顯示包含台中的所有班次

## 🔍 智能檢測機制

### AI會自動檢測包含以下關鍵詞的消息：

#### 車資相關詞彙
- 車資、費用、金額、收費、錢、價格、票價

#### 查詢動詞
- 查詢、查、看、顯示、搜尋、找、修改、改、更新、設定

#### 地點關鍵詞
- 台中、彰化、南投、診所、醫院、火車站、高鐵、機場

### ⚠️ 注意事項

1. **必須同時包含車資詞彙和查詢動詞**才會觸發AI功能
2. 如果AI沒有檢測到您的查詢，系統會提供建議範例
3. 所有查詢結果限制在50筆以內，按日期和時間排序

## 🎊 系統整合

### 與現有功能的協作
- **不影響傳統命令** - 所有原有的「班次詳情」、「指派司機」等命令依然正常使用
- **操作提示** - AI查詢結果會提供相關的操作建議
- **無縫切換** - 可以在AI查詢後直接使用傳統命令進行後續操作

### 建議工作流程
1. 使用AI查詢找到目標班次
2. 記下班次ID
3. 使用傳統命令進行詳細操作（如指派司機、修改狀態等）

## 🚀 快速開始

### 第一次使用
1. 輸入：`查詢今天車資`
2. 查看AI回覆格式
3. 嘗試不同的查詢方式
4. 體驗車資修改功能

