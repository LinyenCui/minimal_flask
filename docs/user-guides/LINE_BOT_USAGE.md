# 📱 Line Bot 完整使用指南

## 🌟 系統概述

派車管理 Line Bot 是一個功能強大的智能派車助手，支援自然語言預約、AI 路線規劃、即時狀態查詢等功能。

## 🔧 基本操作

### 📋 行程管理

#### 查看行程
```
今日行程          # 查看今天的所有行程
明日行程          # 查看明天的行程
本周行程          # 查看本週行程
下周行程          # 查看下週行程
[日期] 行程       # 查看指定日期行程，如：2025/7/28 行程
```

#### 新增預約
```
預約 [時間] [起點] 到 [終點]
新增 [時間] [起點] 至 [終點]
安排 [時間] 從 [起點] 去 [終點]

範例：
預約 2025/7/28 09:00 台北車站 到 松山機場
新增 明天下午2點 公司 至 客戶辦公室
安排 下周一早上8點 從飯店 去會議室
```

#### 修改預約
```
修改預約 [預約編號]
取消預約 [預約編號]
刪除預約 [預約編號]

範例：
修改預約 T20250728001
取消預約 T20250728002
```


## 🤖 AI 智能功能

### 📝 自然語言預約
系統支援自然語言輸入，無需嚴格格式：

```
明天早上9點半要去桃園機場
下周一中午從台北101到信義區
需要大車，載5個人去宜蘭
今天下午3點左右到火車站接人
週五傍晚送客戶到飯店
```

### 🌍 多語言支援
支援中文和日文混合使用：

```
明日の朝8時に空港まで
来週の火曜日に台北駅から
明天朝7時 空港送迎お願いします
```

### 📸 圖片識別
傳送包含文字信息的圖片，AI 會自動解析：
- 📅 會議通知截圖
- 📧 郵件內容
- 📝 手寫便條
- 🎫 票券信息

### 🧠 智能路線規劃
```
建議路線 從 [起點] 到 [終點]
最佳時間 去 [目的地]
避開塞車 到 [地點]
最短路徑 [起終點]

範例：
建議路線 從台北車站到桃園機場
最佳時間 去松山機場
避開塞車 到信義區
```

### 🎯 智能推薦
```
附近司機          # 推薦最近的可用司機
最適合的車        # 根據需求推薦車輛
最佳出發時間      # 建議最佳出發時間
預估費用          # 預估行程費用
```

## 💡 使用小技巧

### ⌨️ 快速輸入
- 使用縮寫：`今日` 代替 `今日行程`
- 數字快捷：`1` 選擇第一個選項
- 時間格式：支援 `9:00`, `9點`, `早上9點` 等多種格式

### 🔍 智能搜尋
- 模糊搜尋：輸入部分關鍵字即可找到相關內容
- 歷史記錄：系統會記住您的常用地點和偏好
- 智能建議：基於使用習慣提供個人化建議

### 📊 批量操作
```
批量修改 [預約編號列表]
批量取消 [預約編號列表]
批量分派 [司機名稱] [預約編號列表]
```

- 所有敏感資料採用加密傳輸

### 🔐 帳號安全

- 不要分享帳號資訊
- 發現異常立即通報
