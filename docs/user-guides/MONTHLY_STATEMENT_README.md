# 月結單功能說明

## 概述

新的月結單功能將原有的「生成月報表 診所」命令升級為Google Sheets格式的專業月結單，提供更清晰的財務對帳和業務分析。

## 功能特色

### 🎯 智能月結單封面
- **Google月結單風格設計**：專業的2欄布局，左資訊右金額
- **自動數據整合**：整合account_ledger和completed_trips數據
- **實時對帳**：自動計算對帳差額並提醒

### 📊 多維度數據分析
- **財務總覽**：月總額、入金清單、銀行帳戶統計
- **司機績效**：前3名司機排名、配班統計
- **業務指標**：配班總數、無金額紀錄筆數

## 使用方法

### 基本命令
```bash
/生成月報表 診所
```
- 生成上一個完整月份的月結單
- 自動使用台北時區計算

### 指定月份
```bash
/生成月報表 診所 2025-07
```
- 生成指定月份的月結單
- 格式：YYYY-MM

### 其他類別
```bash
/生成月報表 東洋
/生成月報表 全部
```
- 東洋和全部類別仍使用原有Excel報表功能

## 數據來源

### Account Ledger (財務數據)
- **月總額**：`account_ledger.weekly_charge` 的 `amount_out` 合計
- **入金清單**：`account_ledger.deposit` 記錄（最多5筆）
- **銀行帳戶**：自動統計最常使用的後四碼

### Completed Trips (業務數據)
- **司機統計**：按司機分組的車資合計
- **配班數據**：診所類別班次統計
- **缺失記錄**：無金額紀錄的班次數量

## 技術實現

### 核心模組
- `modules/services/statements.py` - 月結單數據服務
- `modules/services/sheets_writer.py` - Google Sheets格式化
- `modules/services/google_sheets_service.py` - Google Sheets API整合

### 數據處理流程
1. **期間計算**：Asia/Taipei時區的月份邊界
2. **數據查詢**：PostgreSQL + SQLAlchemy
3. **格式轉換**：ZoneInfo時區處理
4. **Sheets創建**：gspread API操作
5. **權限設置**：公開可查看權限

### 時區處理
- 所有時間計算使用 `Asia/Taipei` 時區
- 數據庫查詢使用 `AT TIME ZONE 'Asia/Taipei'`
- 顯示格式：`YYYY/MM/DD HH:MM`

## 部署注意事項

### 環境變數
- `GOOGLE_APPLICATION_CREDENTIALS_JSON` - Google服務帳戶憑證
- 或使用 `/etc/secrets/credentials.json` 文件

### 依賴套件
- `gspread>=5.0.0` - Google Sheets API
- `google-auth` - Google認證
- `zoneinfo` - 時區處理

### 權限要求
- Google Sheets API 讀寫權限
- Google Drive API 文件創建權限

## 故障排除

### 常見問題
1. **認證失敗**：檢查Google服務帳戶憑證
2. **數據為空**：確認account_ledger和completed_trips有數據
3. **時區錯誤**：確認系統時區設定為Asia/Taipei
4. **權限不足**：檢查Google API權限設定

### 日誌檢查
```bash
# 查看月結單生成日誌
grep "月結單" /var/log/app.log

# 查看Google Sheets API日誌
grep "Google Sheets" /var/log/app.log
```
