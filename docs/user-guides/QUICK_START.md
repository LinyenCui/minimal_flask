# 🚀 快速入門指南

本指南將幫助您快速上手派車管理系統，在 5 分鐘內開始使用核心功能。

## 📱 Line Bot 基本操作

### 🔑 加入系統
1. 掃描 QR Code 加入派車管理 Line 群組
2. 等待管理員授權您的帳號權限
3. 收到歡迎訊息後即可開始使用

### 💬 基本命令

#### 📅 查看行程
```
今日行程
明日行程  
本周行程
```

#### 🚗 新增預約
```
預約 2025/7/28 09:00 台北車站 到 松山機場
明天下午2點 從公司到客戶那邊
```

#### 🔍 查詢功能
```
司機狀態
車輛狀態
幫助
```

## 🤖 AI 智能預約

### 📝 自然語言預約
系統支援自然語言輸入，您可以用平常說話的方式預約：

```
明天早上9點半要去桃園機場
下周一中午從台北101到信義區
需要大車，載5個人去宜蘭
```

### 🌐 多語言支援
支援中文和日文預約：

```
明日の朝8時に空港まで
来週の火曜日に台北駅から
```

### 📸 圖片識別
可以傳送包含時間、地點信息的圖片，AI 會自動解析並建立預約。

### ⚡ 緊急預約
在緊急情況下，在訊息前加上 "緊急" 字樣：
```

緊急 機場接送來不及了
```
