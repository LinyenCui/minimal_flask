🟢 怎麼判斷 Render 端 AI 沒有正確連線？

1. 觀察 AI 信心指標
	•	本地端 AI 查詢有 high，Render 端 AI 查詢是 low（甚至進入 fallback 流程）。
	•	本地能「理解自然語言→正確查詢表」，Render 端只會回單純查詢、數量爆增，這明顯是「AI無法參與判斷」的表現。

2. 檢查 Render Log（這是關鍵！）
	•	進入 Render 的專案後台，打開 log 面板（通常叫Service Log、App Log、Error Log）
	•	搜尋：google.auth、Gemini、anthropic、openai、credential、key not found、environment、Unauthorized、Exception
	•	通常會看到類似：
Default credentials not found
GOOGLE_APPLICATION_CREDENTIALS not set
401 Unauthorized
API key missing
...
這類訊息就是 AI/LLM backend 沒連上的證據。

3. 檢查 Render 端環境變數（Environment Variables）
	•	Render 必須手動設定各種 API 金鑰、JSON 憑證或 Service Account
	•	檢查環境變數裡有沒有設 GOOGLE_APPLICATION_CREDENTIALS（Gemini/Vertex）、OPENAI_API_KEY、ANTHROPIC_API_KEY 等
	•	缺一不可！有時候本地 .env 正確、render 沒設，結果就差這裡。

⸻

🛠️ 如何修復？

1. 上傳憑證檔、設定環境變數
	•	Google Gemini/Vertex AI：
	•	上傳 service account json（或 copy 內容存成環境變數）
	•	在 Render 環境變數加上：
GOOGLE_APPLICATION_CREDENTIALS=/etc/secrets/your_gcp_sa.json
或直接用環境變數方式設一個長字串

	•	OpenAI/Claude：
	•	直接設 OPENAI_API_KEY 或 ANTHROPIC_API_KEY 到環境變數

2. 重啟 Render 服務
	•	設定完後記得「重啟」應用，讓新環境變數生效

3. 查看 Log 確認沒有 Credential Error
	•	log 裡如果沒出現缺憑證/認證錯誤訊息，就表示成功！

⸻

	2.	檢查環境變數/Secrets，是否和本地一致
	3.	缺就補，補完重啟
