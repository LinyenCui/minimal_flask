# LINE Bot AI 功能測試指南

## 🎯 如何驗證您的 AI 功能真正在工作

### 📱 **方法1: 預約叫車功能測試**

1. **在 LINE 中發送**: `預約叫車`
2. **然後發送自然語言**: `明天下午3點從高鐵站到診所`

**✅ AI 工作的證據**:
- 立即解析並顯示結構化信息
- 無需逐步填寫表單
- 回應速度約2-3秒

**❌ 如果 AI 沒工作**:
- 會要求您逐步輸入日期、時間等
- 無法理解自然語言

---

### 📱 **方法2: AI 車資查詢測試**

發送以下任一訊息:
- `查詢今天司機123的車資`
- `7/5司機533診所班次`
- `昨天的診所班次費用是多少`

**✅ AI 工作的證據**:
- 顯示 `🔍 AI智能搜索` 標題
- 能夠理解複雜的自然語言查詢
- 回應包含解析過程說明

**❌ 如果 AI 沒工作**:
- 回應 "不確定如何處理" 
- 只提供基本幫助訊息

---

### 📱 **方法3: 未知命令測試**

發送一些系統不認識的自然語言:
- `我想要預約後天的班次`
- `幫我查一下司機的工作安排`

**✅ AI 工作的證據**:
- 嘗試理解並提供相關回應
- 提取關鍵信息並確認

**❌ 如果 AI 沒工作**:
- 直接回覆 "不確定如何處理"
- 提供一般性幫助訊息

---

### 📊 **方法4: 檢查日誌**

如果您有應用日誌存取權限，尋找:
```
INFO - Calling Gemini API model: gemini-2.0-flash-001...
INFO - Gemini API response received.
INFO - Successfully parsed JSON: {...}
```

---

### ⚠️ **重要提醒**

1. **環境變數設置**: 
   - 應用啟動時必須設置 `GOOGLE_APPLICATION_CREDENTIALS` 等環境變數
   - 重啟應用讓環境變數生效

2. **成本監控**: 
   - 每次自然語言處理 = 1次API調用
   - 複雜對話可能需要 2-3次調用
   - 定期檢查 Cursor Dashboard 的使用量

3. **降級機制**: 
   - 如果API失敗，系統會自動使用本地算法
   - 用戶體驗不會中斷，但就不會消耗額度

---

### 💡 **測試建議**

- **檢查使用量變化**: 如果真的調用AI，使用量會增加
- **觀察回應差異**: AI模式 vs 傳統模式的回應明顯不同
