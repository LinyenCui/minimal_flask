# 清理功能使用指南

## 概述
清理功能專門用於清理trips表中的過去資料，幫助保持資料庫的整潔和效能。此功能與匯入固定班次功能完全獨立，不會影響當前和未來的班次。

## 基本命令格式
```
清理trips [選項]
```

## 可用選項

### 1. 清理已完成
```
清理trips 已完成
```
- **功能**：清理所有狀態為「已完成」的班次
- **範圍**：不限日期，所有已完成狀態的班次
- **用途**：定期清理已執行完成的歷史班次

### 2. 清理過去
```
清理trips 過去
```
- **功能**：清理所有過去日期的班次
- **範圍**：日期小於今天的所有班次（不管狀態）
- **用途**：清理歷史資料但保留當前和未來的班次

### 3. 清理全部
```
清理trips 全部
```
- **功能**：清理所有過去日期的班次（包括已完成和未完成）
- **範圍**：日期小於今天的所有班次
- **用途**：與「清理過去」功能相同

## 使用範例

### 顯示清理選項
```
清理trips
```
系統會顯示所有可用的清理選項和說明。

### 執行清理
```
清理trips 已完成
清理trips 過去
清理trips 全部
```

## 安全機制

### 時間保護
- **不影響今天**：今天的班次不會被「清理過去」或「清理全部」影響
- **不影響未來**：未來的班次完全不會被任何清理選項影響
- **只清理過去**：所有清理選項都只作用於過去的資料

### 狀態保護
- **清理已完成**：只清理已完成狀態的班次，保留其他狀態
- **清理過去/全部**：清理所有過去日期的班次，但保留當前和未來

```
🗑️ 已清理 45 筆已完成狀態的班次
```

### 清理過去日期的班次
```
🗑️ 已清理 123 筆過去日期的班次（保留今天和未來的班次）
```

## 最佳實踐

### 1. 定期清理建議
- **每週清理**：使用「清理trips 已完成」清理已執行完成的班次
- **月度清理**：使用「清理trips 過去」清理所有過去日期的班次
- **季度清理**：全面清理過去資料，優化資料庫效能

### 2. 清理時機
- **週日晚上**：清理已完成的班次
- **月底**：清理過去月份的所有班次
- **系統維護時**：進行全面清理

### 3. 注意事項
- 清理操作不可逆，請確認後再執行
- 清理不會影響報表功能（報表使用completed_trips表）
- 清理後可以改善查詢效能

## 與其他功能的關係

### 與匯入固定班次的區別
- **匯入功能**：專門處理固定班次的匯入和覆蓋
- **清理功能**：專門清理trips表中的過去資料
- **完全獨立**：兩功能互不影響，可單獨使用

### 與報表功能的關係
- **不影響報表**：報表功能使用completed_trips表
- **trips表清理**：不會影響歷史記錄的查詢
- **效能提升**：清理後可改善當前班次的查詢速度

## 錯誤處理

```
🗑️ 可用的清理選項：

• 清理trips 過去 - 清理所有過去日期的班次
• 清理trips 全部 - 清理所有過去日期的班次（包括已完成和未完成）
```

### 系統錯誤
```
⚠️ 清理trips資料失敗: 錯誤詳情
```

## 技術實現

### 清理邏輯
- **已完成**：`DELETE FROM trips WHERE status = '已完成'`
- **過去**：`DELETE FROM trips WHERE date < '今天日期'`
- **全部**：`DELETE FROM trips WHERE date < '今天日期'`

### 事務保護
- 所有清理操作都在事務中執行
- 發生錯誤時自動回滾
- 詳細的日誌記錄
