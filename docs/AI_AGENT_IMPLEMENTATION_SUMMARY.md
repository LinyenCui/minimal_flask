## 🔧 技術實現細節

### 工具標準化
```python
# 工具定義示例
ToolDefinition(
    name="query_dongyang_trips",
    category=ToolCategory.QUERY,
    description="查詢東洋/臨時未完成班次，支援日期參數",
    parameters=[
        ToolParameter(
            name="date", 
            type="date", 
            description="查詢日期，格式YYYY-MM-DD或自然語言",
            required=False,
            default="today"
        )
    ],
    handler_module="modules.services.trip_query_service",
    handler_function="handle_query_dongyang_trips_flex"
)
```

### AI 工作流程
```
用戶輸入 → 路由器判斷 → AI Agent 處理 → 工具執行 → 結果回應
    ↓           ↓            ↓           ↓        ↓
  自然語言    路由決策     思考規劃     動態調用   自然語言
```

### 智能路由決策
```python
# 路由策略
if is_traditional_command(message):
    return False  # 使用傳統處理
elif has_complex_scenario(message):
    return True   # 使用 AI Agent
elif ai_score > 0.6:
    return True   # 使用 AI Agent
else:
    return False  # 使用傳統處理
```
