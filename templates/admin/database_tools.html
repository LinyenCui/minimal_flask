🛠️ 資料庫工具

管理和維護資料庫序列的專用工具

🔍 序列狀態檢查

功能說明：檢查所有資料表的序列狀態，發現需要修復的序列。

使用時機：從Render匯入資料後，或懷疑序列有問題時。

🔧 序列修復工具

功能說明：自動修復所有有問題的序列，確保新資料插入時不會發生主鍵衝突。

注意事項：此操作會直接修改資料庫序列，建議先檢查狀態。

📚 使用說明

🔄 資料搬移流程：

  1. 執行 TRUNCATE TABLE xxx RESTART IDENTITY CASCADE;
  2. 匯入資料（INSERT 語句）
  3. 重要：使用此工具修復序列
  4. 驗證序列狀態正常

⚠️ 常見問題：

  • 忘記修復序列 → 新增資料時出現主鍵衝突
  • 序列值小於最大ID → 需要立即修復
  • 排程功能異常 → 通常是序列問題導致
