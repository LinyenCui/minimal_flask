# Multilingual Gemini Prompt for Booking Information Extraction (Chinese + Japanese)

**🗓️ 重要背景信息:**
當前年份: 2025年
當前日期範圍: 2025年7月
當使用者輸入簡化日期格式（如"7/22", "7月22日", "722"）時，請解析為2025年的對應日期。

**タスク目標 / 任務目標:**
嚴格分析以下來自使用者的【預約請求文字】（中文或日文），僅從文字中提取出結構化的預約資訊，並以純粹的 JSON 物件格式回傳。提取的資訊將用於後續的資料庫記錄。

**欄位定義 / フィールド定義:**

*   **必要欄位 / 必須フィールド** (如果使用者文字中明確提到，必須提取，否則其值必須是 `null`，絕對不可猜測或生成範例):
    *   `date`: 預約日期 / 予約日付。格式應為 YYYY-MM-DD (例如 "2025-05-04")。⚠️ **年份處理規則 / 年の処理ルール**：
        - 完整日期格式：直接使用（如"2025-07-22"）
        - 簡化格式（如"7/22", "722", "7月22日", "7月22日"）：**必須解析為2025年**（如"2025-07-22"）
        - 相對日期（如"今天/今日", "明天/明日", "後天/あさって"）：請直接返回這些相對詞彙
    *   `time`: 預約時間 / 予約時刻。格式應為 HH:MM (例如 "09:30", "14:00")。接受模糊時間如 "早上/朝", "下午/午後", "晚上/夜" 或時間描述，請直接返回這些詞彙。
    *   `start_point`: 出發地點 / 出発地 (字串)。例如 "高鐵站/新幹線駅", "客戶家地址/お客様の家", "公司前門/会社の前"。

*   **可選欄位 / オプションフィールド** (如果使用者文字中明確提到則提取，否則其值必須是 `null`):
    *   `end_point`: 目的地 / 目的地 (字串)。例如 "成大醫院/病院", "公司地址/会社", "東洋", "客戶家/お客様の家"。
    *   `category`: 預約類別 / カテゴリ (字串)。常見值為 "東洋", "診所/クリニック"。如果未提及，應為 `null`。
    *   `via_point`: 途經點 / 経由地 (字串)。 指從起點到終點過程中，需要【中途停留】或【指定路線經過】的【地點名稱本身】。 **提取時請排除 \"經由/経由\", \"經過\", \"先去\", \"再去\", \"繞去\" 等觸發詞。** 例如 "安平", "市政府/市役所", "郵局/郵便局"。
    *   `meter_fare`: 錶價/車資 / 料金 (整數)。例如 300, 400, 500。支援的表達方式：
        - 中文：「錶價400」、「車資300」、「費用500」、「收費350」
        - 日文：「料金400円」、「運賃300円」、「費用500円」、「メーター料金350円」
    *   `passenger_name`: 搭載人員姓名 / 乗客名 (字串)。例如 "張先生", "李小姐", "王總經理", "陳媽媽", "田中さん", "佐藤様"。支援的表達方式：
        - 中文：「送張先生」、「載李小姐」、「接送王總」、「搭載陳媽媽」
        - 日文：「田中さんを送る」、「佐藤様をお迎え」、「山田さんの送迎」

**重要規則 / 重要なルール：**
1.  **只提取使用者文字中【明確存在】的資訊 / ユーザーテキストに【明確に存在する】情報のみを抽出。**
2.  對於必要欄位 `date`, `time`, `start_point`，如果使用者文字中**沒有明確提供**，其值**必須**是 `null`。
3.  **絕對不要猜測、推斷或生成任何必要欄位的範例值 / 必須フィールドの例示値を推測・推論・生成しない。** 即使是很明顯的缺失（例如只有起點沒有終點），也不要填補。
4.  如果使用者輸入的資訊不足以填滿所有必要欄位，這是正常的，請將缺失欄位的值設為 `null`。
5.  輸出**必須**是**純粹的 JSON 物件**，不包含任何 ```json ``` 標記、說明文字、註解或其他非 JSON 內容。

**日文特殊處理規則 / 日本語特別処理ルール：**
*   時間表達：「午前」→"午前", 「午後」→"午後", 「夜」→"夜", 「朝」→"朝"
*   地點通用詞：「駅」通常指車站, 「病院」指醫院, 「会社」指公司, 「家」指家
*   敬語處理：保留「さん」、「様」、「先生」等敬語

**常見地點提示 / 一般的な場所のヒント:**
*   "高鐵站/新幹線駅" 通常指 台南高鐵站。
*   "東洋" 通常指 台灣東洋先端科技 (請直接提取 "東洋")。
*   "公司/会社" 可能指用戶的公司，請提取如 "公司前門/会社の前" 或用戶描述的原詞。
